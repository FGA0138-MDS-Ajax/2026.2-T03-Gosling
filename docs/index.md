# VolunJá

O **VolunJá** é uma aplicação web proposta pelo **grupo Gosling** para conectar voluntários e organizações do terceiro setor. A proposta reúne vagas de voluntariado e permite buscar oportunidades compatíveis com os interesses, a localização e a disponibilidade de cada pessoa, com foco na experiência do usuário. O voluntário também pode consultar suas candidaturas ativas em um calendário pessoal, e o sistema impede novas candidaturas com horários sobrepostos.

Este site reúne a documentação do projeto desenvolvido na disciplina **Métodos de Desenvolvimento de Software (MDS), semestre 2026.2**.
