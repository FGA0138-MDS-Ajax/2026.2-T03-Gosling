# VolunJá

O **VolunJá** é uma aplicação web proposta pelo **grupo Gosling** para conectar voluntários e organizações do terceiro setor. A proposta reúne vagas de voluntariado e permite buscar oportunidades compatíveis com os interesses, a localização e a disponibilidade de cada pessoa, com foco na experiência do usuário.

Este site reúne a documentação do projeto desenvolvido na disciplina **Métodos de Desenvolvimento de Software (MDS), semestre 2026.2**.
